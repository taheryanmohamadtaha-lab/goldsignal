# طلاسنج (GoldSignal Iran)

برنامهٔ ویندوز (Python / PySide6) برای نمایش قیمت، محاسبهٔ حباب، تحلیل تکنیکال، سیگنال و هشدار بازار طلا و سکهٔ ایران.

> ⚠ **این ابزار توصیه مالی نیست و ریسک بازار با کاربر است. هیچ سیگنال یا سودی تضمینی نیست.**

## قابلیت‌ها
- قیمت: امامی، نیم، ربع، گرمی، طلای ۱۸ گرم، مثقال، دلار، اونس
- حباب و ارزش ذاتی، اختلاف قیمت (مبلغ و درصد)، واحد تومان/ریال، ارقام فارسی/انگلیسی، تاریخ شمسی
- نمودار کندل (۱ساعته، ۴ساعته، روزانه، هفتگی) + EMA/SMA/Bollinger/RSI/MACD/ATR + حمایت‌مقاومت + الگوهای کندلی (انگلفینگ، پین‌بار، دوجی)
- سیگنال خرید/فروش/نگه‌داری با ورود، حد ضرر، هدف، R/R، درجه اطمینان و دلیل متنی؛ ثبت تاریخچه و نرخ موفقیت واقعی
- **تحلیل تصویر چارت** (بدون API): اسکرین‌شات چارت کندلی را بدهید، دو قیمت روی محور را مشخص کنید و تحلیل/پیشنهاد/سیگنال بگیرید
- بک‌تست (سود/زیان، Drawdown، Win Rate، Profit Factor)
- هشدار قیمت/حباب/سیگنال با Toast، صدا و System Tray؛ اجرای خودکار با ویندوز (اختیاری)
- خروجی CSV / Excel / PDF؛ تم روز/شب؛ فونت وزیرمتن جاسازی‌شده
- بدون قفل‌شدن UI (شبکه در Thread جدا)، کش SQLite، کار با قطع اینترنت

## نصب (کاربر عادی)
1. از بخش **Releases** مخزن فایل `GoldSignal-Setup-x.y.z.exe` را دانلود و نصب کنید (یا نسخهٔ portable را از zip باز کنید).
2. ویندوز ممکن است هشدار SmartScreen بدهد، چون برنامه امضای دیجیتال ندارد: «More info ← Run anyway».
3. برنامه را باز کنید ← **تنظیمات** ← یکی از این‌ها را انجام دهید: ثبت قیمت دستی، ایمپورت CSV، یا تعریف منبع JSON (راهنما: `docs/data-sources.md`).

## اجرا از سورس
```
python -m pip install -r requirements-dev.txt
python -m pytest
python run.py
```
ساخت EXE: `python -m PyInstaller goldsignal.spec --noconfirm` (خروجی `dist/GoldSignal`)، سپس Inno Setup روی `installer/goldsignal.iss`.

## تحلیل با تصویر چارت
منو ← «تحلیل تصویر». تصویر را باز کنید یا اسکرین‌شات را بچسبانید، روی دو ردیف از تصویر کلیک و قیمتشان را وارد کنید (کالیبراسیون)، تایم‌فریم را بزنید و «تحلیل» را بزنید.
- برنامه کندل‌های سبز/قرمز را از روی رنگ پیدا می‌کند، قیمتشان را با مقیاس خطی حساب می‌کند و همان قوانین EMA/RSI/MACD/حمایت‌مقاومت را اجرا می‌کند.
- برای نتیجهٔ بهتر: حداقل ۳۰ کندل، کندل‌های پهن‌تر (زوم)، بدون اندیکاتور/متن روی کندل‌ها، بدون بخش حجم داخل قاب انتخابی، مقیاس لگاریتمی خاموش.
- محدودیت‌ها: دقت در حد پیکسل؛ فقط کندل سبز/قرمز (یا وارونه با گزینهٔ رنگ)؛ تایم واقعی کندل‌ها از تصویر خوانده نمی‌شود؛ حداکثر اطمینان ۷۰٪؛ این روش حتماً از دادهٔ واقعی API دقت کمتری دارد.

## نحوهٔ خواندن سیگنال
- **اقدام**: خرید فقط وقتی EMA9 از بالا EMA21 را قطع کند؛ فروش برعکس؛ در غیر این‌صورت «نگه‌داری».
- **اطمینان** (۰ تا ۱۰۰): فقط جمع امتیاز قوانین هم‌جهت (RSI، MACD، الگوی کندلی، حباب) است، **نه احتمال سود**.
- **حباب بالا** اطمینان خرید را کم می‌کند (حباب نسبت به میانگین تاریخی خودش سنجیده می‌شود).
- **حد ضرر/هدف** با ATR محاسبه می‌شود (پیش‌فرض ۲×ATR و R/R = ۲).
- **نتیجه** در جدول سیگنال‌ها: «موفق» اگر قیمت بعدی به هدف برسد، «ناموفق» اگر به حد ضرر برسد.
- قوانین در تنظیمات ← پیشرفته (JSON) قابل تغییرند.

## عیب‌یابی
- «داده کافی نیست»: تاریخچه کم است؛ CSV وارد کنید یا چند روز برنامه را روشن بگذارید.
- حباب نمایش داده نمی‌شود: هر سه قیمت سکه، دلار و اونس لازم است.
- «منبع در دسترس نیست»: اینترنت/آدرس منبع را چک کنید؛ آخرین داده کش‌شده نشان داده می‌شود.
- لاگ‌ها: `C:\Users\<شما>\.goldsignal\goldsignal.log`، دادهٔ برنامه: `goldsignal.db` همان‌جا.
